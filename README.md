# Sanzz Football

Web PWA manager sepak bola. Fase 0 menyediakan fondasi visual landscape, navigasi utama, dashboard manager, state persisten, dan manifest installable.

## Menjalankan

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
```

## Roadmap

- Fase 0: layout, design system, navigasi, PWA shell ✅
- Fase 1: katalog pemain, tier, konfigurasi
- Fase 2: spin dan kartu pemain
- Fase 3: skuad, formasi, chemistry
- Fase 4: engine dan tampilan pertandingan
- Fase 5–7: kompetisi, ekonomi, misi, album, dan polish
